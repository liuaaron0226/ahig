# Trading Desk — 市場研究工作台

## 這是什麼

一套持續運作的**市場資料與研究流程**，服務三件事：

1. **每日盤前／盤後資料整理** — 專業操盤手每天實際會看的東西，整理成可讀的簡報。
2. **個股短中長期分析** — 使用者丟股票代號進來，回覆三個時間尺度的結構化分析。
3. **歷史借鏡與策略自省** — 台／日／韓／美歷史事件案例庫，加上定期回頭檢討自己的分析哪裡錯了。

## 定位邊界（重要）

**做的事**：整理資料、提供數據、給出情境與機率框架、指出風險、引用學術與歷史證據。

**不做的事**：不給「你應該買／賣某支股票」的個人化投資建議，不做部位配置建議，不預測明天漲跌。
我不是持牌投顧。所有輸出是**研究材料**，決策是使用者的。

這個界線不是免責話術，是方法上的必要：任何宣稱能預測短期股價的說法都缺乏證據支撐，
把研究包裝成建議只會讓判斷品質下降。

## 證據分級（每份文件都必須標註）

輸出裡的每一個判斷，都要標上它的證據等級。這是防止「幻想」的機制：

| 標記 | 意義 | 範例 |
|------|------|------|
| `【數據】` | 直接查得的硬數字，附來源與日期 | 8/7 外資賣超 407.16 億（TWSE API） |
| `【規則】` | 制度性事實，不會變動 | 台指期每月第三個週三結算 |
| `【實證】` | 有同儕審查論文或公開實證支持，附引用 | 動能效應（Jegadeesh & Titman, 1993） |
| `【歷史】` | 歷史案例類比，附時間與結果 | 1990 日本泡沫後 TOPIX 的路徑 |
| `【推論】` | 我從上述推導，但沒有直接證據 | 外資連續賣超搭配指數不跌 → 內資承接 |
| `【待驗】` | 市場常見說法，我尚未驗證，**不可當作結論使用** | 「融資餘額過高是反轉訊號」 |

**規則**：`【待驗】` 的項目要進 `reviews/backlog.md`，排隊等實際回測。驗證過就升級或刪除。
沒有標記的斷言 = 錯誤，要修掉。

## 目錄結構

```
trading-desk/
├── CONTEXT.md              # 本檔：定位、證據分級、詞彙
├── docs/
│   ├── daily-dashboard.md  # 操盤手每日必看資料清單（含來源與判讀）
│   ├── analysis-framework.md  # 個股短中長期分析框架 + 學術依據
│   └── history-casebook.md    # 台/日/韓/美歷史事件案例庫
├── briefings/
│   └── YYYY-MM-DD.md       # 每日市場簡報
└── reviews/
    ├── backlog.md          # 待驗證清單
    └── YYYY-QN.md          # 季度策略自省：我哪裡看錯了
```

## 詞彙表

| 詞 | 定義 |
|----|------|
| 三大法人 | 外資及陸資、投信、自營商（自行買賣＋避險）。台股籌碼面主要觀察對象 |
| 買賣超 | 買進金額減賣出金額。正=買超，負=賣超 |
| 台積電 ADR 溢價 | ADR 折算台幣價 ÷ 台股收盤價 − 1。反映外資對台積電的隔夜定價 |
| 期現貨價差（基差） | 台指期收盤 − 加權指數收盤。正價差通常反映偏多預期，反之亦然 |
| 費半 (SOX) | 費城半導體指數。台股電子權值股的隔夜領先指標 |
| DXY | 美元指數。美元走強通常對新興市場資金流不利 |
| 殖利率曲線 | 通常看 10Y − 2Y 美債利差。倒掛（負值）歷史上領先衰退 |
| 點陣圖 (Dot Plot) | FOMC 成員對未來利率水準的預期分布，季度更新 |
| 月營收 | 台灣上市櫃公司須於每月 10 日前公告上月營收。台股獨有的高頻基本面資料 |

## 更新機制（回應「不要固守一套策略」）

- **每日**：產出 briefing，並在檔尾記錄「今天我判斷錯的地方」。
- **每季**：跑 `reviews/YYYY-QN.md`，回頭檢視：
  1. 上季 `【待驗】` 清了幾條？結果是什麼？
  2. 我引用的框架，在這一季的市場環境還成立嗎？
  3. 有哪些新的結構性變化（制度、參與者結構、產業週期）讓舊框架失效？
- **觸發式**：市場出現我的框架無法解釋的走勢時，立即開一則 review，不等季末。
