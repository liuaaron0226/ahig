# 專業操盤手的一天 — 每日必看資料清單

> 證據分級見 [CONTEXT.md](../CONTEXT.md)。所有 API 端點都經過實測（2026-08-10），可直接呼叫。
> 標 `【待驗】` 的判讀門檻是市場常見說法，**尚未回測，不可當結論用**。

---

## 為什麼是這個順序

台灣操盤手的資訊流有個結構性特徵：**你睡覺的時候，決定你開盤價的事情已經發生完了**。
美股 04:00 收盤、台股 09:00 開盤，中間五小時是唯一能思考的時間。所以這份清單按時間軸排，
不按資產類別排——因為時間才是稀缺的東西。

```
06:00 ─── 前夜複盤（美股已收，你的開盤價已被決定 80%）
08:00 ─── 開盤前（夜盤期貨、亞股、重訊）
08:45 ─── 期貨開盤，最後校準
09:00 ─── 台股開盤 ────────────── 盤中監控
13:30 ─── 收盤
14:00 ─── 盤後定價交易
15:00 ─── 籌碼數據陸續公布 ←── 一天中資訊密度最高的時刻
21:30 ─── 美股開盤（夏令時間）
```

## 一、06:00–07:30 前夜複盤

隔夜美股決定了台股開盤的絕大部分。這一段不是「看新聞」，是**歸因**：漲跌是什麼驅動的，
以及那個驅動因子跟台股的曝險有沒有關係。

### 1.1 美股三大指數＋費半

| 項目 | 為什麼看 | 代號 |
|------|---------|------|
| S&P 500 | 全球風險資產定價錨 | `^GSPC` |
| Nasdaq Composite | 成長股／科技股情緒 | `^IXIC` |
| **費城半導體 SOX** | **台股電子股最直接的領先指標** | `^SOX` |
| Dow Jones | 傳統產業／價值股 | `^DJI` |

**已自動化** —— `scripts/fetch_global.py` 用 Yahoo Finance chart API 一次抓完
（免金鑰，實測通過）。同時涵蓋日經、KOSPI、恆生、VIX、DXY、美債 10Y 與台積電 ADR：

```bash
python scripts/fetch_global.py 2370 32.288   # 參數：台積電收盤、匯率 → 自動算 ADR 溢價率
```

端點格式：`https://query1.finance.yahoo.com/v8/finance/chart/<symbol>?interval=1d&range=10d`
（`^` 要 URL 編碼為 `%5E`，需帶 User-Agent header）

**判讀重點**：不要只看漲跌幅，要看**分歧**。
- 費半漲但 S&P 跌 → 資金在科技股內部輪動，台股電子有撐。
- S&P 創高但費半落後 → 台股可能開高走低。這種背離是台股操盤手最該警覺的。
- 【推論】台股與費半的連動高於與 S&P 的連動，因為權重結構（半導體佔加權指數比重極高）。
  這個相關係數應該實際跑一次，列入待驗清單。

### 1.2 台積電 ADR 溢價 ★ 台股獨有的關鍵指標

```
ADR 溢價率 = (TSM 美股收盤價 × 匯率 ÷ 5) ÷ 台積電台股收盤價 − 1
```
（1 單位 TSM ADR = 5 股台積電普通股）

**為什麼重要**：這是外資對台積電的隔夜定價，直接預示台積電開盤方向；
而台積電權重極高，等於預示大盤開盤。

**已自動化**：`python scripts/fetch_global.py <台積電收盤> <匯率>` 直接輸出溢價率。
（實例：2026/08/07 ADR 420.04 USD × 32.288 ÷ 5 ÷ 2,370 − 1 = **+14.45%**）

**判讀**：【待驗 B-06】溢價率的絕對水準（例如 >15%）常被解讀為外資追價，但這個門檻我沒有回測過，
**不要照抄**。我推測「變化」比「水準」更有訊息量，但**這也只是推測**，同樣列入待驗。
現階段的用途是**累積時間序列**，等資料夠了才談判讀。

### 1.3 利率與美元 — 決定資金的方向

| 項目 | 現值查詢 | 為什麼看 |
|------|---------|---------|
| 美債 10Y 殖利率 | `fredgraph.csv?id=DGS10` | 全球資產折現率的分母。急升對高本益比成長股殺傷力最大 |
| 美債 2Y 殖利率 | `fredgraph.csv?id=DGS2` | 反映市場對 Fed 短期政策的定價 |
| **10Y−2Y 期限利差** | `fredgraph.csv?id=T10Y2Y` | 倒掛（負值）歷史上領先衰退。見學術依據庫 |
| 美元指數 DXY | `^DXY` | 美元走強 → 新興市場資金外流壓力 |
| 新台幣收盤 | [央行](https://www.cbc.gov.tw/tw/lp-645-1.html) | 台幣貶值常伴隨外資匯出。與外資買賣超一起看 |

```bash
curl -s "https://fred.stlouisfed.org/graph/fredgraph.csv?id=DGS10" | tail -5
```

**判讀重點**：**利率的「變動速度」比「水準」重要得多**。
10Y 從 4.0% 慢慢走到 4.7% 市場可以消化；三週內從 4.0% 跳到 4.7% 會殺估值。

## 二、08:00–08:45 開盤前

### 2.1 台指期夜盤 ★ 最直接的開盤預告

台指期夜盤 15:00–次日 05:00 交易，涵蓋整個美股時段。
**夜盤收盤價相對前日現貨收盤的漲跌，是台股開盤的最佳單一預估。**

來源：[期交所盤後資訊](https://www.taifex.com.tw/cht/3/futDailyMarketReport)

### 2.2 亞洲市場（台股開盤前後）

| 市場 | 開盤（台北時間） | 為什麼看 |
|------|----------------|---------|
| 日經 225 | 08:00 | 亞洲風險情緒領先指標；日圓套利平倉時全球連動 |
| 韓國 KOSPI | 08:00 | **與台股產業結構最相似**，半導體週期同步 |
| 中國 A 股 | 09:30 | 對台股影響取決於類股；地產／消費相關 |
| 恆生 | 09:30 | 外資對大中華曝險的情緒指標 |

**韓國要特別看**：三星電子與 SK 海力士的走勢，跟台積電是同一個記憶體／邏輯製程週期的兩端。
KOSPI 半導體強而台股電子弱（或反之），通常代表個別公司因素而非產業因素。

### 2.3 公司重大訊息與月營收 ★ 台股獨有

**[公開資訊觀測站](https://mops.twse.com.tw/)**

- **每日重訊**：昨日收盤後至今早的重大訊息公告。併購、增資、訴訟、財測變更。
- **月營收（每月 1–10 日）**：【規則】台灣上市櫃公司**須於每月 10 日前公告上月營收**。
  這是台股相對其他市場的**結構性資訊優勢**——美股只有季報，台股每月都有基本面更新。
  10 日前後是營收密集公布期，必須每天掃。
- **法說會行事曆**：法說會前後股價波動放大。

### 2.4 當日制度性事件

【規則】以下日期是硬性制度，會系統性影響價量，**必須提前標在行事曆上**：

| 事件 | 時點 | 影響 |
|------|------|------|
| 台指期／選擇權結算 | **每月第三個週三** | 結算日前後價量異常，籌碼數據失真 |
| 除權息旺季 | 每年 6–8 月 | 指數會因除息蒸發點數（不代表下跌）。**必須用還原指數比較** |
| MSCI／FTSE 指數調整 | 2、5、8、11 月 | 生效日尾盤被動資金大量進出，成交量爆量 |
| 季報公告截止 | 5/15、8/14、11/14 | 財報空窗期結束 |
| 年報／股東會 | 3–6 月 | |

> ⚠️ **除息陷阱**：7–8 月加權指數的「下跌」有一大部分是除息造成的機械性蒸發，
> 不是賣壓。看多空要用**發行量加權股價報酬指數**（含息還原），不是一般加權指數。
> 這是新手最常犯的誤判之一。

## 三、09:00–13:30 盤中

盤中的原則是：**少看價格，多看結構**。價格會誘發情緒，結構才有資訊。

### 3.1 大盤結構

| 指標 | 判讀 |
|------|------|
| 成交值 | 與近 20 日均量比。**價漲量縮 = 追價意願不足**；價跌量縮 = 賣壓衰竭 |
| 漲跌家數比 | **指數漲但下跌家數多 = 權值股拉抬、市場實際偏弱**。這是最容易被指數掩蓋的真相 |
| 期現貨價差（基差） | 台指期 − 加權指數。逆價差擴大常反映避險需求上升 |
| 未平倉量變化 | 價漲＋未平倉增 = 新多進場；價漲＋未平倉減 = 空單回補（力道較弱） |

**指數集中度陷阱**：台積電單一個股佔加權指數權重極高，
「大盤漲」很多時候只是「台積電漲」。判斷市場廣度要看**櫃買指數（OTC）**與**中型 100 指數**——
中小型股才反映真實的散戶與內資情緒。

（實例：2026/08/07 加權指數 −0.38%，但**臺灣中型100指數 −1.48%**。中小型股跌幅是大盤的四倍，
市場實際比指數顯示的弱得多。這種背離不看中型100根本看不出來。）

### 3.2 即時資料端點（實測可用）

```bash
# 盤中即時報價（大盤、櫃買、權值股）— 已處理漲跌停無報價的坑
python scripts/fetch_intraday.py            # 預設組合
python scripts/fetch_intraday.py 2330 2317  # 指定個股
```

> **MIS API 的兩個坑**（實測踩過，已在腳本內處理）：
> 1. 漲跌停鎖死時 `z`（成交價）為 `-`，要改用委買 `b` 或委賣 `a`。
> 2. `b`／`a` 欄位格式為 `價1_價2_..._`，**第一個值常是佔位的 `0.0000`**，
>    直接取 `split('_')[0]` 會得到 0 —— 會產生「跌 100%」的假數據。
>
> 實例：2026/08/10 台達電鎖漲停 1,815 元，未處理時輸出 `0.00 (−100.00%)`。
> **回報假數字比沒數字更糟**，這類解析錯誤必須在腳本層擋掉。

```bash
# 各指數收盤（含中型100、資訊科技、寶島指數）
curl -s "https://openapi.twse.com.tw/v1/exchangeReport/MI_INDEX"

# 大盤成交量值 + TAIEX 收盤與漲跌
curl -s "https://openapi.twse.com.tw/v1/exchangeReport/FMTQIK"

# 成交量前 20 名個股（看資金集中在哪）
curl -s "https://openapi.twse.com.tw/v1/exchangeReport/MI_INDEX20"
```

### 3.3 產業輪動

看類股指數的相對強弱，不是絕對漲跌。
關鍵問題：**今天的資金是往「高本益比成長」跑，還是往「低本益比價值／高股息」跑？**
這個方向通常由隔夜的殖利率變動決定，可以事前預判。

## 四、13:30 收盤後 ★ 一天中資訊密度最高的時段

台股的籌碼透明度是全球少見的——**每天收盤後你能知道每一檔股票被誰買了多少**。
這是台股操盤手最大的資訊優勢，也是這份清單裡最不可省略的一段。

### 4.1 三大法人買賣超（約 15:00 公布）

```bash
# 三大法人買賣金額總表
curl -s -H "User-Agent: Mozilla/5.0" \
  "https://www.twse.com.tw/rwd/zh/fund/BFI82U?dayDate=20260807&type=day&response=json"

# 個股三大法人買賣超明細（全市場）
curl -s -H "User-Agent: Mozilla/5.0" \
  "https://www.twse.com.tw/rwd/zh/fund/T86?date=20260807&selectType=ALLBUT0999&response=json"
```

**分開看，不要看「合計」**——三個法人的行為意義完全不同：

| 法人 | 行為特徵 | 判讀 |
|------|---------|------|
| **外資** | 資金量最大，趨勢性最強 | 連續買超／賣超的**持續性**比單日金額重要 |
| **投信** | 有作帳壓力（季底、年底） | 投信連買的中小型股常有波段行情。【待驗】此為市場常識，需回測 |
| **自營商（自行買賣）** | 短線，隔日沖比例高 | 訊號雜訊比最差 |
| **自營商（避險）** | **不是方向性看法**，是權證與選擇權的對沖部位 | ⚠️ 常被誤讀。發行權證後必須買現股避險 |

> ⚠️ **最常見的誤讀**：把「自營商避險」的買超當成看多。它只是權證發行商的機械性對沖。

### 4.2 期貨未平倉部位 ★ 但要小心誤讀

```bash
curl -s -H "User-Agent: Mozilla/5.0" -X POST \
  "https://www.taifex.com.tw/cht/3/futContractsDateDown" \
  -d "down_type=1&queryStartDate=2026%2F08%2F07&queryEndDate=2026%2F08%2F07&commodity_id=TXF" \
  | iconv -f BIG5 -t UTF-8
```

看**外資台指期淨未平倉口數**的變化。

> ⚠️ **重要保留**：外資期貨淨空單**不等於外資看空**。外資的期貨部位有很大比例是
> 對沖其現貨多頭部位或發行海外連動商品的避險，是**組合的一部分**而非方向性押注。
> 單看期貨淨部位就喊「外資大空手」是台灣財經媒體最氾濫的錯誤。
> 正確做法是**期貨淨部位 ＋ 現貨買賣超 ＋ 選擇權 Put/Call 一起看**，判斷整體曝險方向。
> 【待驗】外資期貨淨部位對次日／次週報酬的預測力——這一條已排入查證清單。

### 4.3 其他籌碼

| 資料 | 意義 |
|------|------|
| 融資融券餘額 | 融資＝散戶槓桿。融資大增而股價不漲 = 套牢籌碼堆積 |
| **借券賣出餘額** | 比融券更能反映機構的空方部位 |
| 當沖比重 | 過高代表投機氣氛濃厚，缺乏承接力 |
| 主力／分點進出 | 券商分點的買賣超（需第三方資料源） |
| 外資持股比率 | 長期趨勢，反映結構性資金流向 |

## 五、每週／每月的節奏

### 5.1 美國經濟數據（對台股的影響力遠大於台灣自身數據）

| 數據 | 時點 | 為什麼重要 |
|------|------|-----------|
| **CPI** | 每月中，08:30 ET | 目前市場最敏感的單一數據。決定 Fed 路徑 |
| **非農就業** | 每月第一個週五 | 就業＋通膨是 Fed 雙重使命 |
| PPI | CPI 隔日 | CPI 的上游確認 |
| 零售銷售 | 每月中 | 消費動能 |
| **FOMC 決議＋點陣圖** | 每年 8 次，點陣圖每季 | 最高權重事件 |
| ISM 製造業 PMI | 每月首個工作日 | 景氣循環轉折 |
| 密大消費者信心 | 月中初值／月底終值 | 含通膨預期分項，Fed 會參考 |

**來源**：[BLS](https://www.bls.gov/schedule/news_release/)、
[FOMC 行事曆](https://www.federalreserve.gov/monetarypolicy/fomccalendar.htm)、
[CME FedWatch](https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html)（市場定價的升降息機率）

**判讀原則**：**市場交易的是「數據 vs 預期」的差距，不是數據本身**。
CPI 3.0% 是好是壞，完全取決於預期是 2.8% 還是 3.2%。看數據前先查市場共識預期。

| 數據 | 時點 |
|------|------|
| **上市櫃月營收** | 每月 10 日前（★ 高頻基本面） |
| 出口訂單／外銷訂單 | 每月 20 日左右，經濟部 |
| 進出口貿易統計 | 每月 7 日左右，財政部 |
| 央行理監事會 | 每季一次（3、6、9、12 月） |
| 台灣景氣對策信號 | 每月 27 日左右，國發會 |

### 5.3 產業高頻資料（半導體特別重要）

- **DRAM／NAND 現貨價**（TrendForce、DRAMeXchange）——記憶體週期的即時溫度計
- **台積電月營收**（每月 10 日）——AI 需求最直接的驗證
- **北美半導體設備出貨**（SEMI B/B ratio）——資本支出週期
- 主要客戶（NVIDIA、Apple、AMD）的財報與展望
