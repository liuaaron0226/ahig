# 個股分析框架 — 短、中、長三層

> 使用方式：使用者丟一個股票代號（例如 `2330`、`TSM`），我照這份框架跑完三層，產出一份分析。
> 證據分級見 [CONTEXT.md](../CONTEXT.md)。

---

## 先講清楚每一層能給你什麼、不能給你什麼

這是整份框架最重要的一段。**三個時間尺度的可預測性差異極大**，
用同一種語氣談三者，是市場分析最常見的欺騙。

| 層次 | 時間尺度 | 主導因素 | 可預測性 | 我能提供的 |
|------|---------|---------|---------|-----------|
| **短期** | 數日–數週 | 籌碼、情緒、流動性 | **極低** | 結構描述與風險位置，**不是方向預測** |
| **中期** | 1–6 個月 | 基本面動能、產業週期 | **中等** | 動能與營收趨勢的證據，有學術支持 |
| **長期** | 1–3 年以上 | 估值、競爭優勢、資本配置 | **相對較高（但變異大）** | 估值區間與商業品質評估 |

**短期那一格的「極低」是認真的。** 任何人告訴你他能預測某支股票未來兩週的走勢，
他要嘛在騙你，要嘛在騙自己。我在短期層只會告訴你**現在的結構長什麼樣、風險在哪裡**，
不會給方向判斷。

## 第一層：短期（數日–數週）— 結構與風險位置

**目的不是預測漲跌，是回答「如果我現在動作，我面對的是什麼結構」。**

### 1.1 籌碼結構（台股獨有優勢）

| 項目 | 怎麼看 |
|------|--------|
| 三大法人近 5/10/20 日買賣超 | 看**持續性**，不看單日金額。連續性比絕對值有意義 |
| 外資買賣超 vs 股價 | 外資買超但股價不漲 → 有其他賣壓；外資賣超但股價撐住 → 內資承接 |
| 投信買超 | 投信連續買超中小型股常伴隨波段。【待驗】需回測 |
| 自營商（避險） | ⚠️ **不是方向性看法**，是權證對沖。不要當訊號 |
| 融資餘額變化 | 融資增而股價不漲 = 散戶套牢籌碼堆積 |
| 借券賣出餘額 | 機構空方部位，比融券更有意義 |
| 當沖比重 | 過高 = 投機盤主導，缺乏承接力 |

### 1.2 量價結構

- **價漲量縮** → 追價意願不足
- **價跌量縮** → 賣壓衰竭
- **價漲量增** → 有實質買盤
- **爆量長黑／長上影** → 出貨或壓力測試

### 1.3 相對位置

- 股價在近 52 週區間的位置
- 相對其所屬類股指數的強弱（超額報酬）
- 相對加權指數的 beta 與近期偏離

### 1.4 短期的學術現實 ⚠️

【實證】短期（1 個月內）股票報酬呈現**反轉**傾向而非延續，這與散戶的直覺相反。
【實證】散戶投資人整體而言在短線交易上是虧損的。台灣證交所的完整交易資料曾被用於
這方面的大規模研究（詳細引用見 `evidence-base.md`）。

**這一層的結論永遠是描述性的，不是指示性的。**

## 第二層：中期（1–6 個月）— 基本面動能

**這是三層中證據基礎最紮實、也最實用的一層。**

### 2.1 月營收趨勢 ★ 台股最強的工具

【規則】台灣上市櫃公司每月 10 日前公告上月營收。這是**每月更新的基本面**，
美股投資人一年只有四次，台股投資人有十二次。

看什麼：

| 指標 | 意義 |
|------|------|
| **月營收年增率 (YoY)** | 去除季節性後的真實成長 |
| **月營收月增率 (MoM)** | 短期動能，但受季節性干擾 |
| **累計年增率** | 平滑後的趨勢 |
| **YoY 的二階變化** | ★ 成長「加速」還是「減速」— 股價常反映的是二階導數 |
| 連續創新高月數 | 動能強度 |

#### ⚠️ 月營收 YoY 的三個資料陷阱（實測發現，非理論）

2026-08-10 我實際把全市場 1,082 家的月營收按 YoY 排序，前十名全是垃圾訊號：

| 代號 | 名稱 | 產業 | 當月營收 | YoY |
|------|------|------|---------|-----|
| 1808 | 潤隆 | 建材營造 | 30.7 億 | **+162,537%** |
| 6934 | 心誠鎂 | 生技醫療 | 0.1 億 | +41,325% |
| 1418 | 東華 | 紡織纖維 | 0.0 億 | +6,800% |

**陷阱一：完工認列型產業**。建設公司（潤隆、順天、遠雄、達麗都在前十）的營收在建案完工時
一次認列，月營收本質上是脈衝而非流量。**對這類公司月營收 YoY 完全沒有意義。**

**陷阱二：小基期效應**。去年同月營收接近零時，YoY 會爆炸成無意義的數字。
篩選時必須設營收絕對值下限。

**陷阱三：產業別必須先分類**。半導體、電子代工的月營收具有連續性與領先性；
建材營造、生技、資產處分型公司則否。**跨產業比較 YoY 是錯的。**

→ 實務做法：篩選前先排除完工認列型產業、設定營收下限（例如 ≥ 5 億）、
並改看**連續數月的 YoY 序列**而非單月數值。

> 【待驗】**常見說法**：股價反映的是「成長率的變化方向」而非「成長率的水準」——
> 一家年增 50% 但上個月是 80% 的公司，股價表現可能差於年增 20% 但上個月是 5% 的公司。
>
> ⚠️ 這個說法直覺上合理（市場定價的是預期的邊際變化），**但我沒有驗證過**，
> 已列入 [backlog B-08](../reviews/backlog.md) 等待回測。在驗證前，
> 請把它當成「值得注意的角度」，不是「已知的規律」。

### 2.2 財報品質

- 毛利率、營業利益率的**趨勢**（不是水準）
- 營收成長 vs 獲利成長是否同步（不同步 = 殺價競爭或成本上升）
- 存貨與應收帳款週轉（存貨暴增 = 需求轉弱的早期訊號）
- 營運現金流 vs 淨利（差距大 = 獲利品質差）

### 2.3 產業週期位置

對台股尤其重要，因為權重集中在半導體與電子：

- 記憶體：DRAM／NAND 現貨價走勢
- 晶圓代工：產能利用率、先進製程佔比、資本支出
- 下游：主要客戶（NVIDIA、Apple、AMD 等）的財報與展望
- 北美半導體設備出貨 B/B ratio

### 2.4 動能效應

【實證】橫斷面動能（過去 3–12 個月的相對強弱延續到未來）是金融學中最穩健的異象之一，
但**有重要的失效情境**（動能崩潰、市場反轉點），且在部分市場（特別是日本）表現異常。
詳細引用與適用邊界見 `evidence-base.md`。

⚠️ **不要把動能當成「漲的會繼續漲」的簡化版**。動能是橫斷面（相對排序）現象，
不是時間序列（絕對趨勢）現象，且在市場劇烈反轉時會出現極大回撤。

### 2.5 預估修正方向

分析師的**目標價水準沒有預測力**（系統性樂觀偏誤），
但**預估修正的方向與幅度**（upgrade/downgrade 的群聚）是有資訊的事件。
看變化，不看水準。

## 第三層：長期（1–3 年以上）— 估值與商業品質

### 3.1 估值（相對自己的歷史，而非相對別人）

| 指標 | 適用 |
|------|------|
| 本益比 (P/E) | 獲利穩定的公司。景氣循環股會誤導（**高點時 P/E 最低**） |
| 股價淨值比 (P/B) | 金融、資產密集產業 |
| EV/EBITDA | 資本結構差異大時 |
| 自由現金流殖利率 | 最難作假的指標之一 |
| 股息殖利率 | 成熟企業 |

> ⚠️ **景氣循環股的估值陷阱**：記憶體、鋼鐵、航運等循環股，在獲利高峰時本益比看起來最便宜
> （因為 E 在高點），那正是最危險的時候。循環股要看 P/B 與循環位置，不是 P/E。

**方法**：把當前估值放在**該公司自己過去 5–10 年的區間**裡看百分位，
再與同業比。跨產業比本益比沒有意義。

### 3.2 商業品質

- **ROE / ROIC 的長期水準與穩定性** — 這是護城河最誠實的量化痕跡
- 毛利率的長期趨勢（持續下滑 = 競爭優勢流失）
- 資本配置紀錄：管理層把賺到的錢拿去做什麼？（再投資報酬率、併購紀錄、庫藏股時機）
- 客戶集中度與議價能力
- 資產負債表韌性（能不能撐過一次完整的下行循環）

### 3.3 結構性風險

- 技術替代風險
- 地緣政治曝險（對台灣企業尤其重要）
- 匯率曝險（出口導向企業）
- 客戶內製化風險
- 法規／碳稅／供應鏈重組

### 3.4 長期的學術現實

【實證】長期股票報酬的可預測性主要來自**估值起點**（買貴了長期報酬就差），
但預測變數的**樣本外**表現遠弱於樣本內，這是文獻中的重要批評。
詳見 `evidence-base.md`。

## 分析產出格式

每次個股分析輸出以下結構：

```markdown
# <代號> <名稱> — 三層分析 (YYYY-MM-DD)

## 摘要
（三句話：短期結構、中期動能、長期估值位置）

## 一、基礎數據【數據】
股價、市值、成交量、52週區間、所屬類股、指數權重

## 二、短期結構（數日–數週）
籌碼 / 量價 / 相對位置
→ 結論為「描述」，不含方向預測

## 三、中期動能（1–6 個月）
月營收趨勢（含 YoY 二階變化）/ 財報品質 / 產業週期位置 / 預估修正
→ 明確標示證據等級

## 四、長期評估（1–3 年+）
估值百分位 / ROE 與資本配置 / 護城河 / 結構性風險

## 五、關鍵變數與情境
列出 3–5 個「會改變上述判斷」的觀察點，以及各自的觸發條件

## 六、歷史類比【歷史】
從 history-casebook.md 找出可類比的歷史情境與其後續發展

## 七、我不知道的事
誠實列出資料缺口與判斷盲區
```

## 我不會做的事

- ❌ 給目標價
- ❌ 說「該買」或「該賣」
- ❌ 建議部位大小或進出場點
- ❌ 預測明天／下週的漲跌
- ❌ 在沒有查證的情況下引用任何數字

這不是保守，是因為**上述任何一項我做了，這份分析的可信度就歸零**。
研究的價值在於它的誠實程度，不在於它的明確程度。
