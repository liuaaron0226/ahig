按鈕範本：6 個方向

六個都用同一套架構（--btn / --btn-hover / --btn-fg 色軸 + 外觀類別），差別只在質感取向。挑一個當預設，或不同專案配不同號。

01

Depth

SmoothUI 原味 · 深色產品站 · 按鈕要有「可按下去」的存在感
box-shadow: 0 1px 2px #00000066, 0 0 0 1px …78%,black, inset 0 .75px 0 #ffffff3d
02

Apple Soft

全圓角 · 靜止時幾乎無陰影，hover 才浮起 · 展示型微網站
靜止 0 1px 1px #0000000f → hover 0 6px 16px -4px（品牌色 55% 透明）
03

Stripe Crisp

小圓角 · 內描邊 + 頂端高光 · hover 上浮 1px · 儀表板／資料密集介面
inset 0 0 0 1px（自身色 70% 混黑）+ inset 0 1px 0 #ffffff2e + translateY(-1px)
04

Glass

液態玻璃 · 只在照片／漸層背景上成立 · hero 疊圖用
backdrop-filter: blur(14px) saturate(1.6) + inset 0 0 0 1px #ffffff40 + inset 0 1px 0 #ffffff66
05

Blueprint

方角 · 等寬字 · hover 掃過一道光 · bixlink 這類工程／技術頁
border-radius: 0 · letter-spacing: .12em · ::after 漸層條 translateX(-101% → 101%)
06

Editorial

無陰影、無漸層 · 純色塊與線 · 閱讀型頁面（grad-exam-hub 那種）
實心色塊 + ::after 底線 scaleX(0 → 1)，完全不用 box-shadow
