# iStudy 課程影片私人備份至 YouTube：工作流程設計

**日期：** 2026-07-23  
**狀態：** 已由使用者核准設計，待實作規劃

## 目標

建立一個安全、可中斷續跑的單機工作流程，處理 iStudy 平台中「115暑電子1」至「115暑電子15」的全部影片。使用者已聲明擁有下載及私人重傳的明確授權，但平台未提供下載按鈕。工作流程優先保存正常播放時可取得的非 DRM 媒體；直接媒體下載依可用網路速度進行，不受播放速度限制。若沒有可直接保存的來源，才以正常播放速度進行授權錄製，確保成品維持原始時長與音訊。完成驗證的影片會上傳至 `liuaaron0226@gmail.com` 所屬的 YouTube，且可見度必須是 Private。

## 非目標與安全邊界

- 不繞過 DRM、Encrypted Media Extensions、授權加密、付費牆、驗證碼或其他存取控制。
- 不猜測、擷取、儲存或自動輸入使用者密碼。
- 不公開、不排程公開、不分享影片連結。
- 不在上傳成功後自動刪除本機影片。
- 不同時處理多部影片，避免重複登入、重複播放及上傳狀態混淆。
- 不修改或搬移使用者既有 Chrome 設定檔；使用獨立的自動化設定檔。

## 架構

### 1. 專用 Chrome 設定檔

工作流程建立獨立的 Chrome 使用者資料目錄。使用者首次執行時，手動確認該 Chrome 使用 `liuaaron0226@gmail.com`，並登入 iStudy 與 YouTube。之後重用同一設定檔的工作階段，避免直接存取 Cookie 或密碼檔，也避免與日常 Chrome 同時搶用相同設定檔。

任何登入失效、重複登入、驗證碼或帳號安全確認都會暫停流程，等待使用者在瀏覽器中完成，不嘗試規避。

### 2. 課程與影片發現

掃描登入後可見的課程清單，只接受標準化後精確落在「115暑電子1」至「115暑電子15」範圍內的課程。每門課程列出所有影片，記錄課程名稱、影片名稱、頁面網址及穩定識別資訊。

發現階段不得啟動批次下載；先建立完整清單，供後續去重與續跑使用。

### 3. 媒體處理策略

每部影片依序嘗試：

1. 在專用 Chrome 中正常開啟影片頁面。
2. 檢查正常播放產生的媒體資訊。
3. 若為普通 MP4 或非 DRM HLS，使用現有登入工作階段允許的請求資料保存媒體。
4. 若沒有可直接保存的來源，但影片可正常播放且不存在 DRM，使用可用的本機錄製工具以正常播放速度錄製畫面與聲音。2 倍速只視為縮短取得時間的偏好，不得讓最終備份影片永久變成 2 倍速或造成音訊失真。
5. 若偵測到 DRM、授權加密、無法確認內容保護狀態，或錄製工具無法可靠取得影音，記錄原因並跳過。

不得因直接保存失敗就假設允許破解或解密。

### 4. 本機驗證

每部影片完成後使用 `ffprobe` 驗證：

- 檔案存在且非空。
- 容器可讀。
- 至少包含有效視訊軌。
- 預期有聲音的內容包含音訊軌。
- 時長為正值，且沒有明顯截斷跡象。

驗證失敗的檔案不得進入上傳佇列。

### 5. YouTube 私人上傳

使用同一專用 Chrome 設定檔開啟 YouTube Studio，一次上傳一部已驗證影片。標題保留課程名稱與原始影片名稱，說明欄不加入公開資訊，也不預設建立播放清單。

可見度由工作流程固定為 **Private**。上傳完成後必須從 YouTube Studio 讀回並確認可見度；若無法確認或不是 Private，標記失敗並停止後續上傳，避免批次產生錯誤可見度。

## 資料與進度

影片依課程存放，例如：

```text
downloads/
  115暑電子01/
    <原始影片名稱>.mp4
```

檔名會移除 Windows 不允許的字元，並避免同名覆寫。進度資料記錄：

- 課程與影片識別資訊。
- 原始頁面網址。
- 本機檔案路徑。
- 使用的處理方式：直接保存或錄製。
- 狀態：已發現、處理中、已下載、已驗證、上傳中、已私人上傳、已跳過或失敗。
- 失敗原因及重試次數。
- YouTube 影片網址或識別碼。
- 已確認的 YouTube 可見度。

進度檔使用暫存檔加原子重新命名寫入。重新執行時，略過已完成且仍通過本機／遠端狀態檢查的項目，不依影片標題單獨判斷是否重複。

## 錯誤處理

- 暫時性網路、播放器或上傳錯誤最多重試 3 次，採逐次增加的等待時間。
- 登入與安全驗證問題不自動重試登入。
- 磁碟空間不足時，在開始下一部影片前停止。
- 部分下載或錄製檔案保留為未完成狀態，不覆寫已驗證成品。
- DRM 或內容保護不列為可重試錯誤。
- YouTube 可見度驗證失敗時停止整個上傳佇列。
- 所有停止原因都寫入最終報告。

## 試跑與完成條件

先只處理「115暑電子1」的第一部影片，完整走過：

1. 發現影片。
2. 直接保存或非 DRM 錄製。
3. 本機影音驗證。
4. 上傳 YouTube。
5. 讀回並確認 Private。
6. 重新執行後確認不會重複下載或上傳。

試跑通過後才處理其餘影片。

整體完成時產生摘要，列出每門課程的發現數、成功數、私人上傳數、跳過數與失敗數。本機已驗證檔案數應與準備上傳的項目數相符；私人上傳成功數應與記錄了 YouTube 識別碼且已讀回 Private 的項目數相符。

## 完成定義

- 所有可合法處理且非 DRM 的影片均已保存或留下明確失敗紀錄。

- 每個成功上傳項目都已確認為 Private。
