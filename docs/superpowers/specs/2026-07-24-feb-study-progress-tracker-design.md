# 讀書模式 → 進度追蹤器 設計 (feb / grad-exam-hub)

- **日期**：2026-07-24
- **檔案**：`grad-exam-hub/site/index.html`（單一靜態頁、client-side、localStorage）
- **狀態**：設計定案，待實作計畫

## 目標

把 `#study`「讀書模式」整塊從**番茄鐘**改成**線上課程進度追蹤器**：使用者把要看完的課程逐堂列出，看完一堂就打勾，即時看到「還剩幾堂、今天該看幾堂、有沒有落後」。綁單一衝刺日 **2026-09-01**。

## 範圍

**移除**（完全換掉）：番茄鐘 SVG 倒數盤、每日番茄目標/連續天數、各科時間長條、休息考點卡(flash)、環球鏡頭(globe/camView)、環境音。連帶的 CSS/JS 一併刪。
`window.camClose` 目前由番茄鐘計時開始時呼叫來關直播鏡頭——鏡頭移除後，這個呼叫點與 `camClose` 一起清掉。

**保留**：整體視覺語言（玻璃卡片、ember/gold、瑞士湖光氛圍背景）、頁面路由/進出動畫、其他 section 不動。

**首頁入口按鈕文字**：`btnStudy` 的副標「番茄鐘・統計・考點卡」→「進度日程・待辦・倒數」。

## 資料模型

課程種子寫在程式碼 `COURSES` 常數（見附錄），首次載入時寫入 localStorage，之後 **localStorage 為準**（讓 App 內新增/編輯/刪除、以及打勾紀錄都持久化，且改課程不會洗掉已勾紀錄）。

```
// localStorage keys
feb.courses.v1  = [{ id, subject, name, sessions:[{ n, title }] }]   // 首次由 COURSES 種入
feb.progress.v1 = { [sessionId]: "YYYY-MM-DD" }                       // 打勾日(本地日期)
feb.sprintDate  = "2026-09-01"                                        // App 內可改
feb.startDate   = "YYYY-MM-DD"  // 首次載入日，配速線用
feb.pace0       = <int>         // 首次載入時的原始每日配速，落後判定用
```

- `sessionId = ${courseId}-${n}`（穩定，改標題不影響已勾狀態）。
- 5 個 subject 分組：多益、工數、線性代數、自動控制、電子學。工數＝微方＋複變兩門課；線代＝線代＋矩陣兩門課；各自獨立卡片、獨立打勾。

## 倒數 / 每日配額 數學

以**本地日期**計算，全域單一衝刺日：

```
X (剩餘)   = feb.courses 中未打勾的 session 總數
D (剩幾天) = max(1, ceil((sprintDate - today) / 1天))     // 到期或過期 → 1
今日配額   = ceil(X / D)                                   // 越拖每天要看越多，自我修正
今日已登記 = progress 中 date == today 的筆數
今日還差   = max(0, 今日配額 - 今日已登記)
```

**落後判定（全域紅標）**：`今日配額 > pace0`，其中 `pace0 = ceil(totalInitial / totalDays)`，`totalInitial`＝首次載入時的總堂數、`totalDays = ceil((sprintDate - startDate)/1天)`，兩者首次載入快照、之後不隨編輯改變。含義：現在的每日必看量超過當初規劃的配速 → 落後、標紅。
（ponytail: 線性配速、開頭快照一次。事後新增課程會合理地把配額推高過 pace0，正確顯示為落後。）

**衝刺日已到/已過**：`today >= sprintDate` 時 D 夾為 1、配額＝X，總覽條顯示「衝刺日已到，剩 X 堂」。

## 畫面（由上而下，沿用漸進揭露）

1. **今日總覽條**（醒目、玻璃）：`離衝刺日 D 天 · 全部剩 X 堂 · 今天該看 ⌈X/D⌉ 堂 · 已登記 M · 還差 K`。落後時整條或配額數字轉紅。
2. **各科分組 → 課程卡片**：每張卡＝一門課，顯示 課名、進度條(已看/總)、剩餘堂數；點卡展開**逐堂 checklist**（`第N講 + 標題`，可個別勾/取消，勾了記今天日期）。勾一堂 → 進度條、總覽條即時更新。
3. **新增/編輯課程**（輕量表單）：科目、課名、貼上逐堂標題（每行一堂）或填總堂數（自動編「第N講」）、可刪課程。→ 備考期間會加新課，不必回頭改 HTML。

## 邊界與持久化

- 勾錯可再點取消（toggle），從 progress 移除該 key。
- 改課程清單（增/刪/改標題）用 `sessionId` 對映，既有打勾不掉。
- 全部日期用本地時區的 `YYYY-MM-DD`（`toLocaleDateString` 或手組），避免 UTC 位移。
- 空狀態：某課全勾完 → 卡片顯示「✓ 已完成」；全部完成 → 總覽條顯示「全部看完 🎉」。

## 明確不做（YAGNI，之後要再加）

- 不做各科各自 deadline（已改綁單一衝刺日）。
- 不做「重設回種子資料」按鈕 → skip，需要時清 localStorage 或再加。
- 不做雲端同步/多裝置 → 單機 localStorage，本來就是。
- 不做每日歷史圖表/連續天數 → 先看得到待辦就好。

## 驗證（一個可跑的檢查）

在 JS 內放一個 `_febSelfCheck()`（`console.assert`），驗配額數學：
`X=126, sprint=2026-09-01, today=2026-07-24` → `D==39 && ceil(126/39)==4`；`today==sprint` → `D==1 && quota==X`；勾掉全部 → `X==0 && quota==0`。開發時呼叫一次。
