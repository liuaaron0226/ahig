# 甲：文獻找得夠不夠齊，怎麼知道

**產生時刻：2026-08-31 02:12 UTC**　（⚠️ 本節數字於產生當下由權威來源現算，🚫 未沿用任何一輪之值）

> **這一節怎麼讀**：每一小段的第一句話是結論，用日常語言寫的。接在後面的是給稽核者查證用的依據。

---

## 一、有一個真實的漏洞，而且它會重複發生

**一句話**：程式分派工作的方式有一個死角，**漏掉了 5 筆紀錄**——而重點不是這幾筆，是**這種分派方式以後還會漏**。

怎麼漏的：紀錄依「歸哪一條線處理」分派工作單，另外用一個「重要傷害訊號」的標記去補死角。**⚠️ 而這 5 筆兩邊都沒接到**——它照分類該進主線，卻不在主線清單裡；它帶著補救標記，卻因為補救清單的條件是「不屬於主線」而也被排除。

> **兩套規則各自都對，漏在它們的交界處。**

**🚨 而該寫進報告的是下面這句通則，不是那幾筆**：

> **工作單的分派，應該用「全部紀錄」當分母去驗證覆蓋率，🚫 而不是分別建單之後假設它們互不重疊又剛好蓋滿。**

⚠️ 同樣的建單方式在後續幾個領域會重複同一個漏洞。

### ✅ 這個漏洞已經補上，而且補的範圍剛好等於漏的範圍

實測：帶著那個標記、又落在主工作單之外的，共 **5** 筆；而另有一份補救用的工作單，**恰好也是那 5 筆，逐筆相同**。

```
交集 5 ｜ 只在補救單 0 ｜ 只在比對樣本 0 ｜ 兩者相同
```

> **🚫 但我們不會寫成「早就預見並補救了」。**
> ⚠️ 「逐筆相同」是**可以驗證的事實**；「當時就有意這麼做」是**意圖**，而我們沒有紀錄可以證明它。**🚨 拿一個沒被證實的意圖去美化一個可驗證的事實，會連那個事實也一起變得不可信。**

## 二、有沒有其他同類的漏洞？**在抽出的那一批裡，一筆都沒有。**

**一句話**：我們拿 **300** 筆紀錄逐一去比對，**每一筆都有著落，沒有解釋不了的**。

當時的疑問是：除了那幾筆，會不會還有別的紀錄同樣掉在分派的縫裡？**若有，代表這個漏洞是系統性的。**

作法：拿那 **300** 筆，**逐筆**和正式各條線的工作單比對，分成四類——在工作單裡／已有解釋的對照樣本／這條線依設計本來就不建單／**沒有解釋的漏口**。

| 處理線 | 在單內 | 已有解釋 | 依設計無單 | **沒有解釋的漏口** |
|---|---|---|---|---|
| 主線 | 0 | **169** | 0 | **0** |
| 安全線 | **52** | 0 | 0 | **0** |
| 動物訊號線 | 0 | 0 | 47 | 0 |
| 綜述來源線 | 0 | 0 | 19 | 0 |
| 註冊資料線 | 0 | 0 | 10 | 0 |
| 身分辨識線 | 0 | 0 | 3 | 0 |
| **合計** | 52 | 169 | 79 | **0**（共 300 筆） |

> **✅ 正式表述**：在這 **300** 筆之中，**沒有解釋不了的漏口（0 筆）**，且**每一筆都被分類，沒有剩下**。

**🚨 而這句話的範圍必須跟著寫，否則它會被讀得比證據強。**

那 **300** 筆**不是全部的紀錄**，是當初為了讓兩套判讀並行而**抽出來的一批**（依分層抽，涵蓋各層）。所以正確的說法是：

| 可以說 | 🚫 不可以說 |
|---|---|
| 在抽出的這 **300** 筆裡，**每一筆都有著落** | 「整批資料都驗過了，沒有漏洞」 |
| 比「抽幾筆看看」強：**這一批裡一筆都沒剩下** | 「這是已驗證，不是沒發現」 |

> **⚠️ 這一段先前寫成「因為母體是全部，不是抽出來的一部分」。****🚨 那句話是錯的**——它是抽出來的一批。⚠️ 對的部分是「**在這一批之內沒有剩下任何一筆**」，**🚫 而那和「整批資料沒有漏洞」不是同一句話。**

**⚠️ 為什麼特別記這一條**：這是整份報告裡**語氣最強的一句**，**🚨 而它的理由本身是錯的。**一個結論就算方向沒錯，**理由錯了照樣要改**——因為下一個人會引用那個理由。

### ⚠️ 而這次比對的第一版是錯的，錯的方向值得寫出來

第一版只分「在工作單內／不在」，於是把兩類**本來就不該進單**的紀錄算成了漏口：依設計不建單的 79 筆、已經有解釋的 169 筆。**得出「落在正式層之外 247 筆」這種嚇人的結論。**

> **🚨 這個錯會把一個乾淨的結果講成重大缺陷。**
> ⚠️ 報告其他地方防的多半是相反方向的錯（把問題讀成正常）——**而這個方向一樣危險：它會讓人去修一個不存在的問題。**

### ⚠️ 還有一項用詞更正，而它剛好是自打嘴巴

我提出這項比對時，把那個「重要傷害訊號」講成一條處理線。**實查：處理線只有六種，裡面沒有它——它是一個標記，不是一條線。**

> **🚨 而第一節講的漏洞，成因正是「線」和「標記」是兩個不同的維度。****⚠️ 我在描述這個混淆的同一份文件裡，又犯了這個混淆。**

## 三、檢索誤命中清單——**這是證據，不是缺陷表**

**一句話**：我們累積了一份「哪些字會誤抓到不相干文獻」的清單，共 **40** 條，**每一條都對應一個真實的誤命中機制**。

舉例：

- `carbohydrate` 也用在生化標記的脈絡裡
- `swim` 會抓到動物行為學的「強迫游泳測試」
- `substrate` 也有酵素受質的意思

> **⚠️ 這份清單越長，代表檢索式被磨得越細，🚫 不是代表錯得越多。**

**⚠️ 清點方式須寫明**：以相異編號計數，**🚨 而檔案裡的編號排列不是遞增的**——🚫 故不可以用「號碼連不連得起來」來判斷有沒有漏。

## 四、這個結論管到哪裡為止

**一句話**：和前面談停止篩選那一節**同一段話、一字不差**。

> **本統計涵蓋宣稱僅及於標準線之 9,091 筆。**
> `animal-signal-review`、`review-source-review`、`registry-review`、`identity-review`
> **各 lane 由確定性路由處置，不在本統計宣稱範圍內**，
> **其未篩狀態是設計使然，且永久保留可稽核。**

**「確定性路由」是什麼**：有四條線不靠人判讀，而是依紀錄本身的性質直接分派——動物研究、綜述來源、註冊資料、身分辨識。**它們不進人工工作單，是設計，不是漏掉。**

**⚠️ 而分派的優先順序本身也是設計，方向是「寧可多篩」**：一筆紀錄若同時符合安全線與其他條件，**優先進安全線**。

> **🚨 這四條線未篩，不影響主線的統計宣稱**——因為那個宣稱從一開始就只涵蓋主線，**而它們的未篩狀態永久保留、隨時可查。**

## 五、這一節的限制

1. **第二節那個「一筆都沒有」，只限那抽出的 300 筆。** 🚫 不可以推廣成「整個流程沒有漏洞」，**🚨 也不可以說成「已驗證沒有」**——⚠️ 那一批是抽出來的。
2. **比對驗的是「紀錄有沒有被分派到工作單」**，**⚠️ 🚫 不是「判讀得對不對」**——那是另一回事，靠抽查與對帳。
3. **誤命中清單不是窮盡的。** 它記的是已經發現的機制，🚫 不保證沒有還沒被發現的。
