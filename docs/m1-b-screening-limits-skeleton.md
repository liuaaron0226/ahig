## 一、判讀之三層界線（皆為設計，非遺漏）

**🚨 本節之主旨**：以下三者都是**刻意畫的界線**，
**⚠️ 讀者若不知其為設計，會全部讀成缺陷。**

| 界線 | 內容 | 為何是設計 |
|---|---|---|
| `[title-only-judged]` | `{{TITLE_ONLY_N}}` 筆僅憑標題判讀 | **上游無摘要可補**，且已逐一嘗試；不判等於留白，判了並標記則可稽核 |
| 33 段不可回溯 | 設計輸入中無 `candidateId` 可對應者 | 機械比對查得了 id 有無、查不了內容有無；**語意比對需要不存在的判準**（n+86 十七） |
| 影子樣本不重判 | 對帳一致者直接成為正式決策 | 雙審查者已一致，重判無新資訊 |

**⚠️ 三者皆須載明筆數與成因**，且 `{{TITLE_ONLY_N}}` 為**漂移值**：
**權威來源為名冊檔本身，🚨 不得以判讀理由文字統計**——早期判讀未必寫該字樣，
**兩種數法實測不相等。**
