## 🚨 先分清兩類數字，否則會用錯規則

| 類別 | 定義 | 交付時的正確動作 | 錯誤動作的後果 |
|---|---|---|---|
| **凍結值** | 終止當下凍結於證據產物內者 | **原樣引用，並附雜湊** | **🚨 重算會毀掉稽核鏈**——凍結證據之所以有效，正因它不隨後續變動 |
| **漂移值** | 名冊筆數、撤稿數、未篩數等隨上游與判讀持續變動者 | **交付時現算，不得沿用任何一輪之值** | 引用舊值會低報或高報 |

**⚠️ 這兩條規則方向相反，套錯任一個都會出事**：
把凍結值拿去重算，等於宣稱「證據是活的」，稽核鏈斷裂；
把漂移值當成凍結值引用，等於拿一個過期的數字當定論。

**判別法**：問「這個數字是不是終止那一刻的狀態的一部分？」
是 → 凍結值；否 → 漂移值。

**凍結參數**（凍結值，原樣引用）：

**⚠️ 須載明凍結時點與其依據**（W7 重放：`{{W7_WALKS}}` 條路徑，

## 五、限制

1. **零命中不等於零遺漏**。正確讀法：**在 `{{SPOT_N}}` 筆隨機抽驗中未發現相關者**，
   不是「剩下的都不相關」。未篩紀錄永久保留可抽查。
2. **排序序列使 p 值偏向樂觀**。工作單依相關性排序，
   而超幾何假定視窗為隨機抽樣；W7 對抗情境之違反率 `{{W7_ADVERSARIAL}}` 即此偏差之量級，
   **尾端抽驗即為對此設計之補償**。**🚨 這一點必須主動寫出，不得省略。**
3. **涵蓋範圍有界**（見第二節），**但範圍有界不等於結論有疑**（檢查表第六條）。
4. **未篩數之來源須聲明**：本 run 有六個判讀來源，
   **漏一個五個數字全錯**（檢查表第四條）。
