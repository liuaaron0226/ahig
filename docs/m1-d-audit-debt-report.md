# 丁：這個流程犯過什麼錯，又守住了什麼

**產生時刻：2026-08-30 03:20 UTC**　（⚠️ 本節數字於產生當下由權威來源現算，🚫 未沿用任何一輪之值）

> **這一節怎麼讀**：每一小段的第一句話是結論，用日常語言寫的。接在後面的是給稽核者查證用的依據。

---

## 一、先講這一節該怎麼用

**一句話**：這一節是整份報告裡**你最判得動的一節**。

你沒辦法自己去判斷那些文獻的結論對不對——**那要讀英文、要懂這個領域**。**但你判得動「這個流程可不可信」**，而這一節就是給你判這件事的材料。

**⚠️ 而它很容易被讀成兩種相反的錯，兩種都會讓你做出錯的決定**：

| 如果你讀成 | 那是錯的，因為 |
|---|---|
| 「他們錯了十幾次，這報告不能信」 | **能列出來的錯，都是被抓到的錯**——一份沒有錯誤清單的報告，通常不是沒犯錯，是沒在看 |
| 「他們有一套會自我糾錯的流程」 | **🚫 沒有這種東西。**會糾錯的是「兩個工作室互相檢查＋規則先寫下來＋刻意放假資料試探」這個安排，**不是其中任何一方** |

## 二、錯誤清單：要看的是「誰抓到的」，不是「有幾條」

**一句話**：我們把每一次犯的錯都記下來，**而最有用的欄位是「這個錯是誰發現的」。**

目前清單有 **19** 列，其中 **18** 種是不同型的錯（**⚠️ 有一列是舊型又犯了一次，🚫 不算新型**）。

**發現來源的分布：**

| 是誰發現的 | 幾次 |
|---|---|
| 另一個工作室抓到的 | **8** |
| 我自己回頭檢查發現的 | **5** |
| 執行室自己招出來的 | **4** |
| 程式自己噴錯攔下的 | **1** |
| 兩個工作室各抓到一例 | **1** |

**⚠️ 這個分布要這樣讀**：

- **如果全部都是自己招的**，你有理由懷疑只挑了好講的講。
- **如果全部都是別人抓到的**，代表自我檢查根本沒作用。
- **四種來源都有，才表示這幾道檢查是真的在各自運作。**

> **🚨 而其中有一列的抓法是「憑直覺覺得這個數字不對」。****⚠️ 那一列若佔比升高，代表檢查有盲區，🚫 不代表直覺很準。**

**⚠️ 上表的歸類是用關鍵字自動分的，須說明它的粗糙處**：同一列若橫跨兩種來源，只會被歸進一格。**🚨 故這張表看的是「四種來源都有」這件事，🚫 不是拿其中某一格的數字去做比較。**

## 三、還沒查完的抽查工作

**一句話**：我們給自己記了一本帳，**列出哪些地方應該再抽查一次確認**。

| | 項目數 |
|---|---|
| 累計記過 | **22** |
| 已經查完 | **6** |
| **還欠** | **16** |

**🚨 這裡的「項」是「抽查工作」，不是「文獻篇數」。**

這一點必須講清楚，因為報告別處會出現「這一批抽查了幾十篇文獻」這種句子——**⚠️ 那是「篇」，這裡是「項」。****🚫 兩個數字並排而不標單位，會被讀成互相矛盾。**

**⚠️ 而且「還欠」和「累計」要一起報。**只報「還欠幾項」，你會以為總共就只抽查過那幾項。

### 影子對帳（完整交代，🚫 不只報結論）

篩選期間我們讓兩套判讀並行，再逐筆對帳：

- 兩邊一致、直接成為正式決定的：**288** 筆
- 兩邊不一致、進入待人工覆核佇列的：**12** 筆

**⚠️ 一致的那批「正式篩選不再重判」**——理由是兩個判讀者已經一致，重判不會帶來新資訊。**🚨 這是一個設計選擇，不是省略，故須寫明。**

## 四、守住的界線——**這一格比錯誤清單更難，也更該看**

**一句話**：錯誤清單講的是「哪裡沒守住」，**這一格講的是「哪裡本來會出錯，但停住了」。**

**⚠️ 只給錯誤清單，你會只看到偵測能力，看不到有沒有在該停的時候停住。**

### 第一則：拒絕把一個成功率套到另一批東西上

先前有 11 篇被網站擋掉，我們改試「同一篇論文的其他位址」，**救回 4 篇**。

後來又有另外 12 篇從來沒試過。**⚠️ 照理可以說「照 4／11 的比例，大概還能救回 4 篇」。**

**🚫 而執行室拒絕這樣推**，理由是：前一批是**出版社擋自動化、別處有副本**；**後一批本身就已經在副本那一端了**——**兩批不是同一種東西**。

| | 篇數 |
|---|---|
| 若照比例外推，預測再救回 | 約 **4** |
| **實際去試，救回** | **0** |

> **🚨 那條界線如果沒守住，報告會多出四篇根本不存在的可取全文。**
> **⚠️ 而它不是靠任何檢查攔下來的**——是靠先問一句「這兩批是不是同一種東西」。

**✅ 這件事可以寫成一條通則**：**一個方法的成功率，其實是「它的前提成立的比率」，🚫 不是這個方法本身有多好。**

### 第二則：沒有順手把後面那道檢查的答案先寫好

有兩個小層在抽樣時合併，**它們的區分依設計要留到讀全文時才做**。而全文已經部分到手，取得階段**其實有能力現在就先分好**——**它沒有分。**

理由是：判斷「腸胃不適是不是主要結果」要讀全文，那是下一階段的工作；**而那個判斷本身，正是這一層要量的東西。**

> **🚨 若取得階段順手分好，那一層就什麼都量不到了**——因為它要量的正是「下一階段分不分得出來」。

**⚠️ 這一則比第一則難**：第一則是拒絕外推，有現成規則可循；**🚨 這一則是察覺「我這一步做下去，會把後面那個檢查的答案先寫好」**——**而沒有任何規則會提醒你，因為那一步本身完全合法。**

## 五、三件必須跟著寫的話

1. **「抓得到錯」不等於「已經沒有錯」。**清單最後幾項都是最近幾輪才加進去的——**🚨 還在增加，就表示同型的錯很可能還有沒被發現的。**

2. **抓到的都是「程式或比對驗得出來」的錯。****⚠️ 判讀本身判對判錯，不在這張清單裡**——那要靠抽查與影子對帳，而抽查還沒查完。

3. **🚫 不可以寫成「這個流程能自我糾錯」。**能糾錯的是那個**安排**：兩個工作室互查、規則先落盤、以及刻意放進假資料看檢查會不會叫。**⚠️ 任何單獨一方都做不到。**
