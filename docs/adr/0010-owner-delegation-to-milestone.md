# ADR-0010：擁有者委任令——全自動化至里程碑

- 狀態：已接受（擁有者 2026-08-14 明示指示：「全部自動化，直到最終成果
  出來再叫我」）
- 日期：2026-08-14
- 情境：房間制（COORDINATION.md 章程）運作正常，但 ADR-0009 的逐批抽查
  門檻與逐項拍板使擁有者成為流程中的同步阻塞點
- ⚠️ **部分已被取代**：決策 3 之 M1 定義已由 **ADR-0016** 取代（M1 改為固定測試集）。🚫 不要照本文的 M1 定義行事。其餘（委任、抽查、契約級變更）仍有效。

## 決策

1. **營運決策委任協調者**：工作包派發、提案核可（如 S2 取得路線）、
   參數選擇、房間調度，由協調者裁定並於看板留痕，不再即時徵求擁有者。
2. **ADR-0009 抽查改為里程碑批次制**：各批 LLM 判讀**先行生效**（標記
   `provisionally-effective`），抽查樣本照常產出並累積為「抽查債」；
   擁有者於里程碑一次清償。若屆時發現系統性錯誤，受影響批次作廢重跑
   ——重工成本是本委任的明示代價，擁有者接受。
3. **擁有者接觸點＝里程碑**。目前定義一個：
   **M1「B.11 校準集就緒」**＝篩選走完（含統計終止證據）→ 60 篇校準集
   依 strata 抽出 → OA 全文取得 → 首輪抽取跑通，附品質報告。
   到達 M1 時一次呈交：成果、累積抽查債、待批契約級變更。
4. **契約級變更仍屬擁有者**（凍結物升版、信任模型再修訂），但改為
   累積至里程碑一併審，除非協調者判斷有不可逆風險才提前打擾。
5. 中途聯絡擁有者的唯一合法理由：不可逆風險、需要付費/帳號授權、
   系統性錯誤導致里程碑不可達。

## 理由

擁有者的時間是本專案最稀缺資源（ADR-0009 的起點）；同步門檻把稀缺資源
放在關鍵路徑上。批次稽核把同樣的誠實檢查移出關鍵路徑——代價（重工範圍
擴大）明碼標價，由擁有者知情接受。

## 後果

- S2 正式提案依本委任即刻生效：W3（regex 升級）、W5（queue 重建，
  前置改為 W3 完成）、W4（兩階段全文設計）進入派發。
- W2 批的 5 筆抽查與後續各批抽查轉入抽查債帳本（看板記錄），M1 清償。
- 協調者承擔更重的把關責任：合併前審查、測試全綠、對抗式審查照舊，
  房間互審文化是委任下的主要品質防線。
