# ADR-0012：路線圖修訂與方法學底線——外部審視後

- 狀態：已接受（擁有者 2026-08-31 三項裁定：睡眠先於壓力進食、咖啡因保留、
  偏誤風險與整體證據確定性納入）
- 日期：2026-08-31
- 取代：ADR-0011 之決策 2、3 之一部分（🚫 其餘各條不變）
- 情境：擁有者委託外部模型審視全案進度。該審視指出三件本案自己沒看見的事：
  路線圖漏了兩個比蛋白質更上游的變項、合成單位是論文而非研究、
  以及一份沒有偏誤風險與整體證據確定性的結論不能拿來做健康判斷

## 決策

1. **P1 併入兩項必要調節變項，不另開 P0**。
   「減脂時肌肉不減」至少由三個槓桿共同決定：熱量赤字幅度／減重速度、
   阻力訓練、蛋白質攝取。原路線圖只寫了第三個。

   > 這不是完整性的潔癖：**一篇受試者未做阻力訓練、赤字又拉到極限的研究，
   > 蛋白質吃再多也保不住肌肉，而那篇會被計為「蛋白質無效」的證據。**
   > 漏掉調節變項，得到的不是不完整的答案，是**錯的**答案。

   外部審視提出可另開 P0，亦自陳「若能直接納入 P1，就不必另開一條巨大工作線」。
   採後者：兩項寫入 P1 的納入條件與分層規則。

2. **領域順序（擁有者 2026-08-31 拍板）**：

   P1 減脂期蛋白質與肌肉保留（含上述兩項調節變項）
   → **P2 睡眠** → P3 壓力性進食。

   擁有者選定睡眠為當前實際瓶頸；ADR-0011 之 P2／P3 相對順序據此定案。

3. **P4 拆為兩題，且咖啡因改掛在 P2 之下**。
   - **肌酸**：獨立小題，池子小，可與 P1 並行。
   - **咖啡因**：擁有者裁定保留。但**問法改變**——
     既然瓶頸是睡眠，值得回答的不是「咖啡因能否提升表現」，
     而是**攝取時機與劑量對睡眠的干擾**。故它是 P2 的子題，不是獨立領域。

     > 外部審視主張咖啡因不應自動保留，除非有具體問題。**現在有了**，
     > 而它指向的是睡眠，不是運動表現。

4. **方法學底線（擁有者 2026-08-31 核准，屬契約級新增）**。
   下列各項自 P1 起適用，B.11 不回頭補做（其角色僅為校準）：

   - **偏誤風險評估**：依研究設計與特定結局，RCT 採 RoB 2 之概念；
     非隨機研究另擇工具。**🚫 不以「這篇看起來可信」代替。**
   - **整體證據確定性**：以 GRADE 之概念，對每個重要結局評估**整體**確定性。
     **單篇論文的品質不等於整體答案的可信度。**
   - **具日期、不可偷改的 protocol**：不必登錄外部平台，但須有版本與修改理由。
   - **review-of-reviews 先行**：P1 的第一步是盤點既有高品質指南與系統性回顧，
     取其搜尋截止日，**只補其後的新研究或其未涵蓋的族群**。
   - **合成單位是研究，不是論文**：`stats/family.py` 已實作而未接線，須接上。
   - **PRISMA 流程與排除理由**：多數數字現成，屬彙整。
   - **資助來源與利益衝突**：納入抽取欄位。
   - **🚫 不做漏斗圖**：研究數少時無辨識力；改以試驗登錄比對、
     protocol 與正式報告之落差、選擇性結局報告來處理 missing evidence 風險。

5. **雙讀之據實名稱**：本案兩位讀者皆為模型，
   **🚫 不得稱為方法學上的「兩位獨立人工審查者」**；
   據實名稱為**雙模型獨立抽取＋衝突裁決**。
   且一致性衡量的是**可靠度，不是正確性**——兩個模型可以高度一致地讀錯同一句話。

## 理由

前四項全部來自外部審視，而本案自己沒看見。第 1 項與第 4 項的
「合成單位是研究」兩者性質相同：**不是做得不夠多，是現有的結果可能是錯的**。
第 4 項是擁有者第一次為「多做一段工作」付出明確代價的決定，其理由亦明確：
沒有偏誤風險與整體證據確定性，最後那句話不能拿來當健康判斷的依據——
而做這個專案的唯一目的就是拿來做健康判斷。

## 後果

- P1 的工時估計**作廢重估**：ADR-0011 引用的 10–15 天只涵蓋「搜尋到全文取得」，
  不含萃取、偏誤風險、歧異裁決與證據合成。**🚫 不得當作 P1 的完成工期。**
- 偏誤風險與整體證據確定性皆需 schema 新增；擁有者已核准，屬 M2 前之前置。
- P1 開工順序因此變成：review-of-reviews → 搜尋契約起草 → 便宜的候選池估算
  → 範圍契約（含兩項調節變項）→ 凍結 → 搜尋 → 篩選 → 萃取。
- B.11 仍受 n+190 之四條內容門檻約束；**🚫 門檻未過不轉場**。
