# ADR-0011：需求驅動的領域路線圖——B.11 僅作校準

- 狀態：已接受（擁有者 2026-08-14 選定順序）
- 日期：2026-08-14
- 情境：原規劃隱含「140 領域全庫」野心，工時模型判定在現有時間預算下
  不可行（2.7 人年）；且 B.11（運動中碳水補給／耐力）與擁有者的實際
  健康需求（重訓、減脂保肌、睡眠不足、壓力性進食）幾乎無關——它是
  方法學壓測場，不是需求標的
- ⚠️ **部分已被取代**：決策 2 之領域順序已由 **ADR-0014** 取代；決策 2 之 P1 題目已由 **ADR-0013** 取代；決策 3 之里程碑定義見 **ADR-0016**。🚫 不要照本文的順序或 P1 題目行事。

## 決策

1. **B.11 的角色限定為校準**：做到 M1（校準集就緒、管線驗證完成）為止，
   不繼續走向 B.11 的證據合成與 Approved Claim。其產出的價值是
   「經實戰驗證的管線＋凍結契約範本」。
2. **領域順序由擁有者需求決定**，首發路線圖（擁有者 2026-08-14 拍板）：
   - **P1 減脂期蛋白質與肌肉保留**：熱量赤字下的蛋白質攝取量、分配與
     重訓配合——直接服務「−18.5 kg 脂肪、肌肉不減」目標
   - **P2 睡眠與減脂／食慾／訓練適應**：睡眠不足的全域影響＋睡眠延長
     介入（Garmin 實測顯示此為共同瓶頸）
   - **P3 壓力性進食的行為介入**
   - **P4 肌酸與咖啡因的實用劑量**（小而快，可與 P1 並行處理）
3. **里程碑重新定義**：M1 = B.11 校準集就緒（不變）；
   **M2 = P1 領域的首批 AI-graded 證據結論**（含 scope/search 契約、
   篩選、校準抽驗、抽取與品質報告，全程 ADR-0009/0010 體制）。
4. 「140 領域」降格為背景目錄：只在擁有者提出新需求時逐一立案，
   不作為進度基準。

## 理由

ADR-0009 已把產出定位為擁有者個人使用；個人使用的系統以擁有者的
健康優先級排序是定義上的正確，照目錄編號排序才是錯置。B.11 的沉沒
成本不浪費——管線、契約範本、判讀慣例、抽查制度全部直接複用。

## 後果

- M1 完成後，協調者立案 P1 的 scope-contract 與 search-contract 起草
  （沿 B.11 範本），走既有房間分工。
- P4 可作為輕量並行線提早開跑（池子預估小一個量級）。
- 工時模型（③）改以 P1–P4 為對象重估，不再以 140 領域為分母。
