# ADR-0008：篩選允許統計終止（statistical termination ≠ 排除）

- 狀態：已接受
- 日期：2026-08-13
- 情境：AHIG B.11 title/abstract screening 契約；與 ADR-0007 同批決策，
  兩者可獨立成立。校準集抽樣 blocker（「篩完才能抽」）是另一份待議 ADR，
  等 prevalence audit 實測數據後另行決策

## 問題

現行契約隱含「候選池必須全數篩畢，篩選才算完成」。這在每領域 144 篇的
原始假設下合理；在實際上萬篇的池子裡，它是 39 週工時牆的直接來源。

技術輔助審查（TAR）領域已有可辯護的替代方案：優先佇列把相關文獻前移，
篩到後段連續出現大量不相關文獻時，以精確超幾何檢定計算「剩餘未篩部分
仍藏有相關文獻」的機率，達到統計信心即停。關鍵工具：

- **BUSCAR**（buscarpy/buscarR，MIT）：唯一輸出「以 (1−α) 信心拒絕
  recall < 目標」這種精確下界的實用實作，且其預設方向是 fail-closed
  ——證據不足時繼續篩，而非停止。
- destiny-evidence/stopping-methods（Repke et al. 2026，81 資料集基準）：
  統計方法可靠但停得保守；knee、SAFE 等啟發式無保證形式，只能當輔助
  訊號。這與本 repo 的 fail-closed 標準一致。

選項：

- **A. 維持全量篩畢**：最嚴格，工時牆照付。
- **B. 統計終止＋尾端標記 not-screened＋終止後抽驗**（採）。
- **C. 啟發式停止（knee/SAFE 單獨使用）**：無統計保證，不過 fail-closed
  標準，拒絕（SAFE 的前置隨機樣本與換模型驗證作為 B 的組件保留）。

## 決策

採 B，新增「統計終止」概念，與被禁止的「自動排除」嚴格區分：

1. **終止的統計條件**：以精確超幾何檢定（buscarpy 或以 scipy 自建同式）
   在 α=0.05 下拒絕「recall < 0.95」才允許終止。參數（α、目標 recall）
   以 destiny-evidence/stopping-methods 在近似資料集上模擬校準後凍結；
   檢定證據不足時的預設行為是繼續篩。
2. **前置條件**：
   - 優先佇列排序生效，且先以隨機前置樣本（SAFE 式，池子的 1–2%）估計
     盛行率、餵養排序模型；
   - `safety-review` lane 與帶 `critical-harms-signal` 的紀錄**全數人工
     篩畢**之後，才允許進入終止評估——harms 不參與提早收工。
3. **尾端的身分**：終止點之後的紀錄一律標記 `not-screened`，不是
   `excluded`。它們保留在池中、永久可抽查，涵蓋宣稱附統計證據而非默認。
4. **終止後驗證**：從 not-screened 尾端隨機抽 200 篇人工抽驗；出現任何
   一篇 include 即恢復篩選，並把事件寫入稽核紀錄。
5. **稽核產物**：p 值軌跡、目標與參數、停止點、尾端抽驗結果凍結為
   artifact 並入雜湊鏈。

機器在整個流程中仍不對任何單篇做決定：統計終止是對「整批剩餘」的涵蓋
宣稱，附帶可抽驗的證據；每一篇被篩過的文獻仍由人類判定。

## 理由

1. 「全量篩畢」的真正目的不是儀式，是涵蓋保證。B 用可辯護的統計下界提
   供同一保證，且以 not-screened 標記誠實記錄「沒看過」與「看過並排除」
   的差別——比默默假設「篩完 = 涵蓋」更 fail-closed，成本低一個量級。
2. BUSCAR 的檢定方向（證據不足 → 繼續）與本 repo 的 fail-closed 文化同
   構；啟發式規則不具此性質，故僅作輔助訊號。
3. 決策成本假設已被實測推翻（144 篇/領域 → 上萬篇），維持 A 的代價不再
   是「嚴謹的合理溢價」，而是讓整個計畫在時間預算內不可行。

## 後果

- 與 ADR-0007 疊加後，篩選牆估計 387 → 約 100–160 小時（39 週 → 10–16
  週）；實際節省取決於排序品質，統計方法傾向保守側停止。
- `RULE_VERSION` 升版；`blockingReasons` 語彙加入統計終止狀態；新增終止
  評估與尾端抽驗的 schema 與工具；`human-title-abstract-screening-not-
  completed` 的完成定義改為「人工篩畢部分＋有效統計終止證據」。
- 新增成本：前置隨機樣本、終止後 200 篇抽驗、參數模擬校準的一次性工作。
- 已知限制：統計保證以「排序與抽樣假設成立」為前提，尾端抽驗就是對這
  個前提的持續檢驗；若抽驗失敗，代價是恢復篩選——fail-closed 的代價方
  向正確。
