# ADR-0016：M1 改為「固定測試集通過內容驗收」

- 狀態：已接受（擁有者 2026-09-02 直接答覆「要」）
- 日期：2026-09-02
- 取代：ADR-0010 決策 3 之 M1 定義（🚫 其委任條款不變）
- 依據：ADR-0015 決策 3（該項當時標為「待擁有者確認」，本 ADR 即該確認）

## 決策

**M1 之定義由「41 篇全部抽取完成並附品質報告」改為：**

> **一組 5–10 篇的固定測試集，通過 ADR-0015 決策 2 之五條內容驗收。**

### 測試集之選取條件（🚨 依已觀察到的失敗型態，🚫 不隨機抽）

每一條**至少各有一篇**涵蓋：

1. **同義儀器名稱**——已知：一篇肌肉切片論文因名稱寫法不同而整篇歸零。
2. **編造數值**——已知：某篇之腸胃症狀項目，全文只出現在方法段的量表清單裡。
3. **出處指錯段**——已知：七項指向方法段而非其宣稱的結果。
4. **對錯結局**——已知：把「30 分鐘自訂配速計時賽的平均功率」宣告為完成時間。
5. **應輸出 `unresolved` 者**——⚠️ 尚無已知實例，**🚨 故須刻意挑一篇資訊確實不足的**。

**⚠️ 另保留至少 2 篇 holdout**：修改後的流程**從未看過**者。
🚫 沒有 holdout，「通過」只證明改到不再犯已知的錯，**不證明它會做對沒看過的東西。**

### 通過即結束 B.11

🚫 不再要求其餘各篇通過；🚫 不對 B.11 產出任何健康結論。
✅ 其餘 30 餘篇之清冊保留為回歸資料，**🚫 不再投入修補。**

## 理由

原定義要求一個**校準領域**達到出版級完整度。
外部審查判定那是「把輔助工具當成主要成果」，而本專案的數字支持它。
**校準的目的是找出機器會怎麼壞，🚫 不是把練習題做完美。**

擁有者之原話：要。**⚠️ 其代價亦已告知**：
🚫 通過之後，「B.11 的 41 篇都被正確抽取」這句話**永遠不會為真**，
✅ 而本專案也不需要它為真。

## 後果

- 📮 執行室：依上述條件選出測試集並列出**篇號與其對應的失敗型態**，
  🚫 不得以「涵蓋各種情況」概括。
- ⚠️ 第 5 條沒有已知實例——**🚨 若挑不出來，如實回報「挑不出」**，
  🚫 不得為了湊滿五條而把不合的篇硬歸類。
- ✅ M2（P1 首批 AI 分級證據）之定義不變，但其前置由「M1 完成」改為本 ADR 之 M1。
