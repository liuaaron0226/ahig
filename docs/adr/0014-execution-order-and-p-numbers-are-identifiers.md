# ADR-0014：執行順序定案，且 P 編號自此**只是識別碼**

- 狀態：已接受（擁有者 2026-08-31 指定順序）
- 日期：2026-08-31
- 取代：ADR-0012 決策 2、ADR-0011 決策 2 之順序部分（🚫 其餘不變）

## 決策

1. **執行順序（擁有者指定）**：

   | 執行序 | 領域 | 識別碼 |
   |---|---|---|
   | 第一 | 壓力性進食 | **P3** |
   | 第二 | 睡眠 | **P2** |
   | 第三 | 減重速度 × 訓練 → 肌肉保留 | **P1** |
   | 未定 | 肌酸 | P4a |
   | 併入 P2 | 咖啡因對睡眠的干擾 | P4b |

2. **P 編號自此只是識別碼，🚫 不代表優先序。**

   > 編號是按**提出的先後**給的，不是按**執行的先後**。
   > 執行順序已與編號脫鉤，而**名稱與內容不符是本案反覆吃虧的那一型**——
   > 故此處明文脫鉤，🚫 不重新編號：重編會讓先前數十處寫著
   > 「P1 蛋白質」的紀錄同時指向兩個不同的東西。

3. **三者皆保留，🚫 不裁掉任何一個。** 擁有者指出這三件在他身上是連著的。

## 理由

擁有者報告的兩個症狀（掉不下去、維持不住）是同一件事，
而對應它的領域先前排在最後。順序據此翻轉。

**併記一項更正**：本案第 494 輪曾說「P1 回答的是他現在還沒有的問題」。
**那句話錯了。** 擁有者說明他**先前減下來時肌肉量也掉很多**——
故那不是他還沒遇到的問題，是**他已經遇過、且一旦重新開始減脂就會再遇到**的問題。
它排第三是因為前面兩件擋住了開始，🚫 不是因為它不重要。

**併記一項證據強度的分辨**：擁有者先前以 InBody 讀數「比平均高」主張蛋白質不是問題，
本案指出那是弱證據。**而這一次的說法性質不同**——
「同一台機器、同一個人、減脂前後的變化」是**個體內的重複量測**，
比「與族群平均比較」可信得多（⚠️ 仍受水分與時段影響，🚫 仍不等於 DXA）。
**故這一次的理由比上一次強，不適用同一句話駁回。**
