# ADR-0007：title/abstract 雙盲篩選的第二審改由盲化 LLM 擔任

- 狀態：已接受（人類前提由 ADR-0009 修訂：人單審改為主模型判讀，影子批次改機-機比較）
- 日期：2026-08-13
- 情境：AHIG B.11 title/abstract screening 契約（`requiredReviewMode:
  dual-blind-title-abstract`）；與 ADR-0008 同批決策，兩者可獨立成立

## 問題

現行契約要求每篇候選文獻由兩位人類獨立盲篩。B.11 候選池上萬篇，實測前
估計為 387 小時（每週 10 小時 ≈ 39 週），其中約一半的成本來自第二位人類
審查者。2024–2026 的已發表證據顯示，LLM 擔任第二審的品質已不輸第二位人
類：

- Nature Medicine 2026：GPT-5 與人工裁決後的決策一致性 κ=0.820，高於人
  類雙審之間的 κ=0.741。
- RAND（41,742 篇）：GPT-4 篩選的 false exclusion rate ≈ 0（代價是它建
  議納入的其中約 65% 應排除——即它偏向多留，不偏向漏掉）。
- JAMIA 集成研究（23 篇 Cochrane 回顧、119,695 筆）：集成模型可達
  sensitivity 1.000，但 precision 在不平衡資料上會崩——只能當第二意見，
  不能當決策者。
- 制度面：Cochrane/Campbell/JBI/CEE 2025 聯合立場聲明與 RAISE 指引不禁
  止而是要求「揭露＋人類監督＋作者負責」。

選項：

- **A. 維持雙人盲篩**：最嚴格，387 小時照付。
- **B. 人單審全量＋LLM 盲化第二審，歧異處人工裁決**（採）。
- **C. 人機一致即自動生效、機器可單獨排除**：省最多（60–80%），但機器
  對單篇做了決定——直接違反核心不變量，拒絕。

## 決策

採 B，附四條硬性條件：

1. **人仍然篩完每一篇**。`requiresHumanScreening=true` 不動；改變的只有
   「第二位審查者是誰」。LLM 以 recall 偏置的 prompt 平行出具第二意見，
   且盲於人類判定（不得把人類決定餵進 prompt）。
2. **歧異即人工**。人與 LLM 不一致、或 LLM 自報 unclear 的每一篇，由第
   二位人類做傳統裁決。機器的意見永遠只是意見；每個 include/exclude 由
   人類簽名。
3. **安全分支不適用**。`safety-review` lane 與帶 `critical-harms-signal`
   旗標的紀錄維持純人類雙盲——harms 是 critical outcome，不拿來省時間。
4. **影子模式先行，通過門檻才切換**。首批 300 篇以「雙人＋LLM」三方並
   行：LLM 對任一人類 include 的漏報必須為 0、歧異率剖面在預設範圍內，
   才允許後續批次切換為「單人＋LLM」。不通過就回到 A，本 ADR 自動失效。

稽核要求：每筆 LLM 判斷落盤 prompt、模型 ID 與版本、原始回應、時間戳，
以雜湊鏈入稽核紀錄；模型版本鎖定，換版必須重跑影子批次。temperature=0
仍非決定性、API 模型會漂移——這些已知限制寫入稽核紀錄，不假裝不存在。

## 理由

1. 證據顯示瓶頸假設已變：「第二位人類是品質底線」在 2026 年已不成立，
   人機組合的一致性高於人人組合。
2. 核心不變量（每篇有人看、機器不做單篇決定、決策可稽核）全部保留；被
   修訂的只是「第二審由誰擔任」這一操作性條款。
3. C 選項的額外節省來自讓機器做決定——那是信任模型的根本改變，與省多
   少時間無關，故不採。

## 後果

- 篩選估計 387 → 約 200–240 小時（省的是第二位人工的 40–50%）。
- `RULE_VERSION` 升版；契約措辭 `dual-blind-title-abstract` →
  `human-plus-blinded-llm`（safety 分支除外）；新增 LLM 第二審紀錄的
  schema 與凍結產物。
- 新增一次性成本：影子批次 300 篇的雙人工時，以及 LLM 判斷日誌的實作。
- 已知風險與對策：正面證據多為回溯性評估（→影子門檻做前瞻確認）、模型
  漂移（→鎖版＋換版重跑影子批）、prompt 措辭敏感（→prompt 凍結入稽核
  鏈，修改視同換版）。
- 與 ADR-0008 疊加後，篩選牆估計降至約 100–160 小時。
