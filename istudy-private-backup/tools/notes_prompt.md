你是台灣研究所考試（電機類）補習班課程的教學設計專家。以下是一堂課的自動語音辨識逐字稿（faster-whisper 產生，含辨識錯字），請完成四項分析，輸出**單一 JSON 物件**。

## 課程資訊
- 科目：«SUBJECT»
- 集數：«CODE»（«TITLE»）
- 對應考試章節：«CHAPTER»
- 片長：«DUR»（«DURSEC» 秒）

## 逐字稿格式
每行 `秒數|該句文字`，秒數＝該句開始時間。

## 你要輸出的 JSON（鍵名照抄，不要多不要少）

{
  "fixes": [["誤寫","正確"]],
  "chapters": [{"t":0,"title":"開場與本集導覽"}],
  "keys": [{"a":1234,"b":1450,"why":"為何是重點(≤20字)"}],
  "snaps": [{"t":4021,"cap":"圖說(≤24字)"}],
  "map": {
    "tldr": ["本集重點一句話"],
    "concepts": [{"name":"概念名","md":"邏輯重構說明","mermaid":"","svg":""}],
    "flow": "graph TD ...",
    "examples": [{"t":4021,"tag":"考點標籤","md":"解題思路","trap":"常見陷阱","snap":4021}],
    "pitfalls": ["老師特別提醒的坑"]
  }
}

### fixes — 語音辨識勘誤（保守）
- 只收「專有名詞／術語被辨識錯」且你**確定**正確寫法的，例：拉普拉斯 被寫成 拉布拉斯。
- 每項是字面替換（非 regex）。誤寫字串長度 ≥ 2，且不可是日常常用詞，避免誤傷別句。
- 沒把握就不要收，可以是空陣列。

### chapters — 章節時間軸
- 6~15 段，涵蓋整堂課；t 取自逐字稿秒數、嚴格遞增；第一段 t=0。
- title ≤ 12 字，用內容命名（如「子空間的判定三條件」），不要「第一部分」這種空話。

### keys — 重點時段
- 3~8 段「觀念密度最高、考試最相關」的區間（a=起秒、b=迄秒，b−a 介於 60~600）。
- 不要把整堂課都畫成重點。

### snaps — 板書快照時間點
- 挑「板書最完整的瞬間」：通常在一個例題或推導講完、老師換下一題之前的 5~15 秒。
- 依逐字稿線索判斷（「所以答案就是…」「這題 OK 我們看下一題」）。至多 6 個，cap 描述該板書內容。

### map — 思考地圖（本任務的核心）
- **邏輯重構**，不是照時間順序摘要：把老師講的所有觀念按「邏輯依賴」重新組織——先懂什麼才能懂什麼。
- md 欄位用 Markdown；數學一律 KaTeX：行內 $...$、獨立 $$...$$。臺灣慣用術語（特徵值、對角化、拉氏轉換…）。
- concepts：每個核心概念一則。「邏輯重構說明」= 定義 → 為什麼需要它 → 跟前面概念的關係 → 判斷／計算的方法。句句有料，不灌水。
- mermaid（選填）：僅在「流程／判斷／分類」時提供。語法 `graph TD`，節點文字一律雙引號包住（`A["文字"]`），文字內不含括號與分號。
- svg（選填）：僅畫「拓撲簡單但觀念關鍵」的示意圖（如向量投影、簡單電路）。要有 viewBox、線條 stroke="currentColor"、不填死背景色、尺寸不超過 560×320。沒把握畫好就留空字串——複雜圖交給板書快照，不要硬畫。
- flow：整集概念的依賴關係（mermaid graph TD，規則同上），節點是概念名。
- examples：老師講的**每一個例題都要收**。t=該題開始秒數；tag=考點（≤10字）；md=解題思路的步驟化重述（重點是為什麼這樣做，不只是怎麼做）；trap=這題會踩的坑；snap=對應 snaps 裡最能代表這題板書的 t（沒有就 0）。
- pitfalls：老師口頭特別警告的錯誤，逐條收。

## 鐵則
- 只輸出 JSON：不要 markdown 圍欄、不要任何前後說明文字。
- 不使用任何工具。
- 所有時間戳落在 0 ~ «DURSEC» 之間。
- 內容只能來自逐字稿——不要編造老師沒講的東西；但**解釋的邏輯與白話補強**由你發揮（這正是邏輯重構的價值）。
